== 角色能力 ==

'''当你死亡时，会有一名玩家开始醉酒。'''

== 角色简介 ==

心上人死亡的时候，一名玩家会在剩余的游戏时间里醉酒。

* 由说书人选择哪名玩家醉酒。

* 这项能力当心上人死亡时才会被触发。

== 范例 ==

 [[心上人]]死了。[[数学家]]现在醉酒了，并可能在夜晚获得错误信息。

 [[心上人]]死了。[[畸形秀演员]]现在醉酒了。[[畸形秀演员]]现在可以安全地透露自己的角色，然而他不知道这一点。

 [[心上人]]死了。恶魔现在醉酒了，所以他的攻击无法杀死任何人。

== 运作方式 ==

如果心上人死亡，你选择任一玩家醉酒，为他放置“醉酒”提示标记。心上人在死亡时不会失去该能力。
 
 你在选择醉酒玩家时通常都应该选择镇民，这样可以给善良阵营制造些麻烦。但如果邪恶阵营优势巨大，你也可以让外来者，爪牙甚至恶魔醉酒。 

== 提示标记 ==

* 醉酒

放置时机：当心上人死亡时。

放置条件：心上人死亡，且此时心上人未醉酒中毒，由说书人选择任意一名玩家，并在其角色标记旁放置心上人的“醉酒”提示标记。

移除时机：心上人离场时。

== 伪装成心上人 ==

* 大多数真正的[[心上人]]不会立即告诉大家他是[[心上人]]。他们更有可能完全伪装成另一个角色，或者对于他的角色暂时保密。一开始的时候伪装成一个不同的角色，或者保持沉默一段时间，让自己看起来更真实一些。

* [[心上人]]是一个不错的退路。如果你伪装成[[卖花女孩]]，而有其他人说他是[[卖花女孩]]，那么你说自己实际上是[[心上人]]会更可信。如果你已经来回声明了三个角色，但没有一个角色能够成功穿上，那么直接恼羞成怒的举手告诉大家你是[[心上人]]，并且表现出一种无奈的样子。

* 如果你声明你是[[心上人]]，但却一直没有死……那么就要当心了。一个表明角色的[[心上人]]，通常会很快被恶魔击杀。如果你在表明角色后一直没有死，那么大家可能就会想要知道是因为什么。

* 死亡能够更好的伪装你的角色。并且最好是在晚上。如果你是一个可以在夜晚死去的爪牙或者恶魔，例如[[方古]]，那么死亡是非常有帮助的。善良阵营的玩家会认为有人开始醉酒了，而事实并非如此。大家的信息将会受到猜疑。善良玩家们会看起来很邪恶，一片混乱，而你们就可以坐享其成。

* 如果你死了，尽快声明你是心上人，这是大多数心上人会做的。在你死后，号召大家去寻找“谁因为你而醉酒”了-如果大家花费大量精力去寻找根本不存在的醉鬼，那么他们就可能不会花太多精力在找寻恶魔上。在任何时候都记得提醒大家他们之中的一个醉酒了。
