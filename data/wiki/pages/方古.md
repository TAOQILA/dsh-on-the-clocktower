== 角色能力 ==

'''每个夜晚*，你要选择一名玩家：他死亡。'''

'''被该能力杀死的外来者改为变成邪恶的方古且你代替他死亡，但每局游戏仅能成功转化一次。[+1外来者]'''

== 角色简介 ==

方古会侵染外来者。

* 方古首次攻击并成功杀死外来者时，改为方古死亡，外来者变成邪恶的方古。

* 这种情况在整局游戏仅能出现一次。如果新的方古攻击外来者，外来者正常死亡。

* 新的方古也是恶魔，如果他死亡，善良阵营获胜。但他不会得知哪些玩家是爪牙。

* 方古会使得在初始设置时增加一名外来者。

* 如果方古攻击外来者，但外来者没有因此死亡，则外来者不会成为邪恶的方古，方古也不会死。

== 范例 ==

 [[方古]]攻击并杀死[[艺术家]]。下个夜晚，[[方古]]攻击了[[心上人]]，[[心上人]]成为新[[方古]]，老[[方古]]死亡。[[心上人]]不会使一名玩家醉酒，因为[[心上人]]没有死。下个夜晚，新[[方古]]攻击并杀死了[[呆瓜]]。

 [[方古]]攻击死去的[[呆瓜]]。因为[[呆瓜]]已经死了，他不会再次死亡，所以[[方古]]不会死。[[呆瓜]]仍然为善良阵营，今晚无人死亡。

== 运作方式 ==

在初始设置时，将角色标记放入盲抽袋前，把一个镇民角色标记替换为一个外来者角色标记。

除首个夜晚外的每个夜晚，唤醒方古。让他指向一名玩家。让方古重新入睡。

如果被选择的玩家不是外来者，为那名玩家放置“死亡”提示标记。

如果被选择的玩家是外来者，且“限一次”提示标记已经被放置在魔典中，也为那名玩家放置“死亡”标记。

如果被选择的玩家是外来者，且“限一次”提示标记不在魔典中，在原来的方古旁放置“死亡”提示标记。唤醒被选择的外来者。依次向他展示“你是”信息标记、向下的大拇指、方古角色标记。用多出的方古标记替换他的角色标记，且他转为邪恶阵营。让新方古重新入睡。把“限一次”标记放在魔典中心。（与“每局游戏限一次”能力不同，这个标记在接下来的游戏中始终留在那里，即使方古死亡或改变角色。）

== 提示标记 ==

* 死亡

放置时机：在方古夜晚行动并选择了玩家后放置。

放置条件：方古选择的玩家当前存活，且能被方古杀死，且方古未醉酒中毒，那么在该玩家的角色标记旁放置，用以提醒说书人在黎明时分宣布当晚的死亡玩家。

移除时机：在黎明时宣布死亡玩家后，说书人可以任由自己方便来进行移除。

* 限一次

放置时机：在方古即将成功杀死一名外来者，但此时魔典中央还未放置“限一次”提示标记时。

放置条件：在方古成功触发能力转化外来者时，放置在魔典中央。

移除时机：持续至整局游戏结束。

== 规则细节 ==

*相克规则：
**[[红唇女郎]]：如果即将出现两名存活的恶魔，其中之一是由红唇女郎转变的，红唇女郎不会变成恶魔。

== 对抗方古 ==

* 知道[[方古]]存在游戏中是打败他的第一步。第一个也是最大的线索就是外来者的数量比平时要多。当然这也可能是邪恶阵营的玩家声称是自己是外来者的结果，也可能是由于[[方古]]造成的。

* 某些角色能够直接发现[[方古]]的存在。每当一个新的[[方古]]出现时，[[神谕者]]能够发现一个新的死亡的邪恶阵营玩家。[[卖花女孩]]能够发现恶魔是否投票，如果投了票的玩家死在夜里，这可能是[[方古]]出现在游戏中的线索。[[筑梦师]]、[[艺术家]]和[[博学者]]有时候也能得到[[方古]]存在于游戏中的信息，当然这些信息不会十分明确的告诉你谁是[[方古]]。如果[[数学家]]一直得到是0的信息，即其他玩家的信息都没有出错，那意味着[[涡流]]和[[诺-达鲺]]不在游戏之中，[[方古]]就可能存在于场上。

* 如果你怀疑[[方古]]在存在游戏之中，就处决外来者。[[方古]]在一整局游戏中不转换外来者的阵营是很少见的，所以外来者特别令人怀疑。最好在游戏末期的时候处决外来者而不是早期，因为越到后期，[[方古]]才更有可能将外来者变成邪恶的新恶魔。

* 如果一名玩家在夜里死亡，请注意他们与谁在交谈。死亡的[[方古]]通常会想要和他的爪牙交谈谁是那个新的恶魔。

* 如果你是一个外来者，在你确定[[方古]]没有存在游戏中之前，请不要暴露你的角色。如果[[方古]]在游戏之中，你可能会在某个时刻突然变成邪恶的恶魔。如果你告诉了善良阵营你是一个外来者，他们可能认为你是邪恶的，然后将你处决。
