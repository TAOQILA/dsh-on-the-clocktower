== 角色能力 ==

'''在你的首个白天，你可以公开猜测任意玩家的角色最多五次。在当晚，你会得知猜测正确的角色数量。'''

== 角色简介 ==

杂耍艺人会冒着风险说服别人在第一天就透露他们的角色，希望尽可能多地猜测说实话的人。

* 在第一个白天，杂耍艺人可以对任意玩家的角色进行猜测。当晚，他会得知他猜对的次数……如果他没有被杀害的话。

* 他必须公开猜测，以使所有玩家听到他猜测的内容。他可以猜测零个角色，或者最多猜测五个角色，他所猜测的玩家和角色可以相同也可以不同。

* 如果杂耍艺人在醉酒或中毒时做出了猜测，但当晚他的能力触发时却清醒且健康，那么说书人仍然会给他真实的信息。

== 范例 ==

 第一个白天，[[杂耍艺人]]猜测小明是[[城镇公告员]]，小兰是[[诺-达鲺]]，小黑是[[贤者]]。当晚，[[杂耍艺人]]得知“2”，这代表他猜对了两个。

 第四个夜晚，[[博学者]]变成了[[杂耍艺人]]。下个白天，新的[[杂耍艺人]]猜测小八是[[麻脸巫婆]]，小八是[[女巫]]，小米是[[麻脸巫婆]]。当晚，[[杂耍艺人]]得知“1”。

== 运作方式 ==

在第一个白天，如果杂耍艺人声明使用他的能力，你需要拿着魔典进入玩家围成的圆圈内。杂耍艺人最多可以做出五次猜测，每次猜测选择一名玩家和一个角色。对于每个正确的猜测，放置一枚“猜测正确”提示标记在杂耍艺人角色标记旁。（确保其他玩家不会看到你放置了几枚提示标记。）

当晚，唤醒杂耍艺人。对他用手势比划等同于“猜测正确”提示标记的数量（0，1，2 等）。让杂耍艺人重新入睡。在稍后说书人方便的时候，移除所有“猜测正确”提示标记以及杂耍艺人的夜晚标记。
 
 如果杂耍艺人猜的太快，让他放慢速度。 

 如果邪恶玩家伪装成杂耍艺人，在他假装进行猜测时，你可以在魔典中假装四处移动标记来协助他进行伪装。 

== 提示标记 ==

* 猜测正确

放置时机：在杂耍艺人宣布公开猜测期间。

放置条件：每当杂耍艺人猜测正确一次，便放置一枚猜测正确标记在杂耍艺人的角色标记旁边。（实际上，你也可以放置在魔典中的其他位置，比如猜测正确的对应角色的角色标记旁，有助于说书人进行一些更详细的记录。）

移除时机：在杂耍艺人获取信息后，说书人可以任由自己方便来进行移除。

== 规则细节 ==

* 不建议杂耍艺人在进行猜测时，多次进行所选玩家与角色的猜测组合完全相同的猜测。（如猜测小明是数学家三次。）但杂耍艺人仍然可以猜测同一名玩家为不同的角色多次，或猜测多名玩家为同一角色多次。

* 如果杂耍艺人的玩家是新人玩家，说书人可以对他进行宽容处理：在他忘记使用自己的能力的当晚唤醒他，并正常告知他信息。此时“0”为正确信息。然而如果是老手玩家，说书人则需要严格进行要求，那名玩家必须要公开声明自己是杂耍艺人之后，才能够在夜晚获得信息（即使他公开声明之后不进行任何猜测，也一样能够获得信息）。

* 相克规则：
**[[食人族]]：如果杂耍艺人在自己的首个白天猜测后在当天死于处决，当晚食人族会替杂耍艺人得知对应的信息。

== 伪装成杂耍艺人 ==
* 别害羞。[[杂耍艺人]]需要公开声明。这意味着不管是说书人还是其他所有玩家都会听到你猜测。杂耍者通常希望尽可能猜到多的人，会尽最大努力让大家相信他是[[杂耍艺人]]，并且会说服大家都透露他们的角色。如果你要伪装成[[杂耍艺人]]，就让大家尽量透露自己的角色。

* 你可以通过只猜测善良玩家并确认他们的角色来使自己更像是善良的。并且被你所确认的善良玩家会更容易相信你。例如，你猜测[[卖花女孩]]是[[卖花女孩]]，[[钟表匠]]是[[钟表匠]]，[[博学者]]是[[博学者]]，然后告诉大家你的猜测都是正确的，这会使你看起来产生了很大的帮助。

* 或者，你可以通过只猜测善良玩家并告诉大家你的猜测不正确而使他们看起来是邪恶的。如果大家相信你是[[杂耍艺人]]，这会使他们之间互相不信任。例如，如果你猜测了[[筑梦师]]、[[艺术家]]、[[女裁缝]]和[[城镇公告员]]，但是你告诉大家你只猜对了3个，这就说明这之中有一个人在撒谎。如果幸运的话，大家可能会想方设法去找出是谁，甚至去处决这些玩家。

* 通过猜测邪恶队友的伪装角色来证实他们。去鼓励他们在第一天就说自己的善良角色是什么，然后声明你的猜测是对的。例如，你猜测[[女巫]]（伪装为[[心上人]]）是[[心上人]]，[[舞蛇人]]是[[舞蛇人]]。然后你告诉大家你得到的都是正确的，那么大家可能会认为女巫是善良的。

* 利用你的能力去使某个玩家的信息不可信并对他产生怀疑。你可以只猜他一个玩家，或者去猜测他与另外一两个大家目前都非常信赖的玩家，然后告诉大家你猜错了。这个技巧在当你选择的是善良的双子时会更加有效，因为这可能会使你们通过触发[[镜像双子]]的能力而赢得游戏。或者，你可以使[[博学者]]或[[钟表匠]]看起来是邪恶的，从而使他的信息变得不可靠，这会给到你们更多的喘息空间。

* 提防那些狡猾的玩家，他们可能会报一个假的角色，一些善良玩家有一些理由而去撒谎。如果他们这么做而你却说你猜对了他们的角色，那么他们就会知道你在撒谎。你当然可以说实际是他们在撒谎，或者你的信息由于[[诺-达鲺]]、[[涡流]]或一个死去的[[心上人]]等影响变得不正确，但通常来说这会更难以相信。

* 假装是[[杂耍艺人]]可以帮助恶魔发现那些有更高优先级的目标。恶魔大部分都想尽快去杀死[[卖花女孩]]、[[神谕者]]和[[博学者]]等目标或其他当前设置里强大的角色。让善良玩家去透露自己的角色有助于帮助恶魔做出选择。当然，在[[梦殒春宵]]剧本中，所有的选择都是不错的选择，但是如果可以根据情况去选择就更棒了。
