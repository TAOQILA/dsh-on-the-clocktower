== 角色能力 ==

'''每个夜晚*，你要选择一名玩家：他死亡。'''

'''镇民玩家的能力都会产生错误信息。'''

'''如果白天没人被处决，邪恶阵营获胜。'''

== 角色简介 ==

涡流使所有信息变得错误。

* 任何时候角色是镇民的玩家通过能力获取信息时，他们会得知错误信息。哪怕他们醉酒或中毒，信息也一定是错误的。

* 涡流不会影响其他人通过其他方式获得的信息，例如说书人解释的规则或玩家的角色或阵营的变化。

* 当夜晚降临时，如果今天白天没有人被处决，邪恶阵营胜利。流放旅行者不算在内。

== 范例 ==

 [[涡流]]杀死了[[贤者]]。[[贤者]]得知了两名玩家，他们都不是恶魔。

 白天没有人投票或提名，但是[[畸形秀演员]]被处决了。当晚，[[卖花女孩]]和[[城镇公告员]]都得知“是”。

 在白天，[[博学者]]得知了两条信息。两条都是错误的。当晚，[[筑梦师]]选择那名[[博学者]]玩家，并得知这名玩家是[[哲学家]]或[[诺-达鲺]]。

 [[麻脸巫婆]]将[[杂耍艺人]]变成[[女巫]]。[[杂耍艺人]]得知他现在是善良[[女巫]]，因为这个信息来自于玩家的角色变化，而非镇民的能力。

 [[涡流]]在场。今天白天，一名玩家因为[[女巫]]能力死亡，两个旅行者被流放，进行了五次提名，但没有人被处决。邪恶阵营胜利。

== 运作方式 ==

只要涡流存活，每当有镇民因为能力需要你提供信息，你就必须提供错误信息。

除首个夜晚外的每个夜晚，唤醒涡流。让涡流指向一名玩家，将该玩家杀死。该玩家死亡，在他角色标记旁放置“死亡”提示标记。让涡流重新入睡。

每个黄昏，如果今天白天没有玩家被处决，游戏结束，邪恶阵营获胜。

== 提示标记 ==

* 死亡

放置时机：在涡流夜晚行动并选择了玩家后放置。

放置条件：涡流选择的玩家当前存活，且能被涡流杀死，且涡流未醉酒中毒，那么在该玩家的角色标记旁放置，用以提醒说书人在黎明时分宣布当晚的死亡玩家。

移除时机：在黎明时宣布死亡玩家后，说书人可以任由自己方便来进行移除。

== 对抗涡流 ==

* 不要惊慌！[[涡流]]表面上看起来很吓人，但是只要善良阵营是聪明的，[[涡流]]可能会提供一个比角色表上的其他恶魔更简单的挑战。即使你完全搞不懂场上的局势，一旦场上只剩下三名玩家存活，你也有三分之一的几率杀死恶魔。所以，这听起来没有那么令人害怕。

* 作为一个团队，你可以通过分享信息来判断场上是否有[[涡流]]在场。善良玩家提供的信息越多，就越容易发现[[涡流]]在场，因为这些信息并没有叠加串联起来形成有用的信息链。一到两条奇怪的信息很容易被当成是[[诺-达鲺]]、[[心上人]]或者一个邪恶的玩家在说谎造成的，但是五到六条对不上的信息通常证明了是[[涡流]]存在于游戏之中。一旦你发现了[[涡流]]存在游戏之之中，即使你不知道恶魔是哪位玩家，这也是善良团队的优势。

* 如果你发现[[涡流]]在游戏之中发挥着作用，那么所有的信息都是虚假的。这听起来很糟糕，但是那实际上非常有用！有了[[涡流]]，信息不再可能是真的。这意味着[[心上人]]或者[[哲学家]]让你醉酒了，他们也不能得到真实的信息。知道所有的信息100%都是假的，意味着你可以简单地把这些信息反过来，这就是真实有效的。例如，如果你不知道哪个恶魔在场发挥着作用，[[卖花女孩]]说恶魔没有投票，[[城镇公告员]]说爪牙没有提名，[[女裁缝]]说[[卖花女孩]]和[[城镇公告员]]是不同阵营的，那么这中间就包含了太多的可能性，这是非常混乱的。但是如果你知道了[[涡流]]在场，那么[[卖花女孩]]就知道恶魔投票了，[[城镇公告员]]就知道爪牙提了名，[[女裁缝]]就知道[[卖花女孩]]和[[城镇公告员]]是同一阵营。这对你的信息有了确定性的帮助（即使你必须不断地将假的信息转变为真的信息）。

* 没有进行处决的话，游戏直接结束。不要跳过处决阶段除非你真的确定没有[[涡流]]在场。（[[涡流]]之所以有这么强大的能力，是为了防止善良阵营故意在第一天不提名处决，让[[神谕者]]、[[卖花女孩]]和[[城镇公告员]]得到错误的信息，以此确定[[涡流]]的存在。）善良团队就应该每天进行提名处决以防止真的涡流在场。显然，处决掉邪恶的玩家最好，但是处决掉善良的玩家比直接输掉比赛要好得多。

* 如果在[[涡流]]存在的游戏中有任何的玩家提供了真实的信息，请处决掉他们。因为他们在说谎。说谎只意味着一件事，他们是邪恶的玩家想要掩盖[[涡流]]存在的事实从而扰乱场上的局势。或者他们是[[舞蛇人]]、[[贤者]]或者[[畸形秀演员]]因为某些原因在隐藏自己的角色从而编造的谎言。但他们是邪恶的可能性更大。

* 有些角色更善于感知[[涡流]]是否在场。因为[[涡流]]强制所有的信息都是假的，所以你可以尝试创造这样一种情况，即你的信息预期会产生特定的结果，并查看你是否得到了这样的结果。举一些例子包括[[艺术家]]（问一个是/否问题）、[[杂耍艺人]]（仅仅猜测他自己）、[[筑梦师]]（可以选择信任的玩家然后看信息是否相匹配）、[[卖花女孩]]（让所有人都投票——如果你得到的是恶魔没有投票，你就得知你的信息是错误的）、[[城镇公告员]]（在一天内只有一个人提名——如果你被告知有爪牙提名，你应该知道如何去做了吧）或者[[女裁缝]]（选择两个你确定知道结果的玩家发动你的能力——尤其是当场上存在[[镜像双子]]的时候！）

* 要小心[[诺-达鲺]]、[[哲学家]]和[[心上人]]——多亏了他们的能力能导致中毒或者醉酒，有些人能得到错误的信息。如果你认为你得到了错误的信息，试着找出这个来源是影响着整场游戏还是仅仅只是影响了你。

* 并非所有能接收信息的角色都能被[[涡流]]影响。比如，[[舞蛇人]]将会得知谁不是恶魔这是因为他的能力带来的副作用效果。正因为如此，他们的信息在[[涡流]]在场时会被认为是真实的。
