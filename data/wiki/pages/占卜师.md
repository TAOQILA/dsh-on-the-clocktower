== 角色能力 ==

'''每个夜晚，你要选择两名玩家：你会得知他们之中是否有恶魔。'''

'''会有一名善良玩家始终被你的能力当作恶魔。'''

== 角色简介 ==

占卜师能探查谁是恶魔，但某些时候也会误以为善良玩家是恶魔。

* 每个夜晚，占卜师需要选择两名玩家，得知其中是否有恶魔。他不会得知具体哪一名玩家是恶魔，只知道两名玩家之中有恶魔。如果两名玩家均不是恶魔，他会得知“否”。

* 不幸的是，会有一名被称作“干扰项”的玩家，会被占卜师在选中时当作恶魔。“干扰项”在一整场游戏中只会是同一名玩家。这名玩家可以是任何善良玩家，甚至是占卜师自己。占卜师不会知道哪一名玩家是他的“干扰项”。

* 占卜师可以选择任意两名玩家——无论他们存活与否，甚至可以选择自己。如果占卜师选中了已死亡的恶魔，仍然会得知“是”。

== 范例 ==

 [[占卜师]]选择了[[镇长]]与[[送葬者]]，并得知了“否”。

 [[占卜师]]选择了[[小恶魔]]与[[共情者]]，并得知了“是”。

 [[占卜师]]选择了一名存活的[[小恶魔]]与一名死亡的[[小恶魔]]，并得知了“是”。

 [[占卜师]]选择了自己与作为“干扰项”的[[圣徒]]。[[占卜师]]得知了“是”。

== 运作方式 ==

在为首个夜晚进行准备时，将占卜师的“干扰项”提示标记放置在任意善良角色标记旁，标记那名玩家为“干扰项”。

每个夜晚，唤醒占卜师。让占卜师指向任意两名玩家。如果这两名玩家中任意一名是恶魔或“干扰项”，对占卜师点头表示“是”。否则，摇头表示“否”。让占卜师重新入睡。

 在小型游戏中（指汀西维尔模式），我们建议你在某些情况下将占卜师本人作为“干扰项”，以使占卜师能通过这种方式得到更多信息。

== 提示标记 ==

* 干扰项

放置时机：在为首个夜晚做准备时放置。

放置条件：放置在任意一个善良玩家的角色标记旁边，可以是占卜师自己。

移除时机：占卜师死亡或离场时。

== 规则细节 ==

* 虽然在[[占卜师]]的角色详解中提及了“‘干扰项’在一整场游戏中只会是同一名玩家”，但这是由于在[[暗流涌动]]中不会出现[[阵营转变]]效果而导致的。不去介绍更深层次的规则仅仅只是不希望玩家在一开始就因为接收到过于复杂的规则而变得迷惑（正常来说，玩家需要进入到[[梦殒春宵]]后才会接触到阵营转变的效果）。实际上，[[占卜师]]的能力包含了动态检测效果，一旦被他标记为“干扰项”的那名玩家变为邪恶阵营，说书人就需要重新选择另一名善良玩家并放置“干扰项”标记。但只要被标记为“干扰项”的玩家阵营没有发生变化，那么他就始终都会是“干扰项”。这种情况其实与得知[[寡妇]]在场的玩家变为邪恶阵营后，会重新有一名善良玩家得知[[寡妇]]在场是类似的。

* 虽然在绝大部分情况下这并没有什么用，但是以为自己是[[占卜师]]的[[酒鬼]]因为不具有[[占卜师]]的能力，也就因此不会有“干扰项”这个标记。[[提线木偶]]同理。

*特定角色互动：
**[[数学家]]：[[占卜师]]因为选择“干扰项”而得知“是”不会计入到[[数学家]]的能力检测中，因为这是他自身能力让自己获取的信息出错。醉酒中毒情况下，[[占卜师]]选择了“干扰项”玩家而得知了“否”时（因为在未醉酒中毒情况下会得知“是”，“看错干扰项”这一能力因为醉酒中毒而未正常生效），会计入到[[数学家]]的能力检测中。
**[[涡流]]：如果[[涡流]]在场，[[占卜师]]仅仅选中了“干扰项”会得知“是”，这是因为[[占卜师]]的获取信息只判断“是否选中了恶魔”，而这次选择他没有选中恶魔，因此得知“是”。
**[[咖啡师]]：[[咖啡师]]的“获取正确信息”效果对[[占卜师]]生效的期间里，会让[[占卜师]]不再把“干扰项”错认成恶魔。

== 伪装成占卜师 ==

当你要伪装成占卜师的时候，这里有几件事你应该记住：

* 你在每个晚上都会醒来（包括第一个晚上），如果你存活的话就会得到信息。当你说你是[[占卜师]]的时候，善良阵营的玩家会让你把每天晚上行动的详细原因说明一下。所以你得提前准备好你要告诉他们什么。

* [[占卜师]]有时候会得到非常令人困惑的信息。[[陌客]]可能被当作恶魔。即便场上没有[[红唇女郎]]，恶魔也能将自己转移到爪牙身上。"干扰项"也能被当作恶魔，这样会导致一个善良玩家看起来很可疑。因此，相比于提供听起来合理且自洽的信息来说，能够自信地行动其实更重要一些。

* 在注意以上几点的情况下，如果你提供给队伍的信息也是一致的，你伪装的成功几率将会大大增加。如果你一遍又一遍地告诉其他人某位玩家不是恶魔，他们就会倾向于让这位玩家保持存活。如果你一遍又一遍地告诉其他人某位玩家可能是恶魔，他们就会倾向于处决这位玩家，但是如果处决之后游戏还在继续进行的话，他们就可能把矛头指向你了。

* 你可以撒谎说"这两个玩家中没有恶魔"，以便保护你的邪恶阵营队友。

* 如果一个善良玩家特别棘手，你就可以声称你查到他是恶魔了，这样可以让大家都把注意力集中在他身上并且迅速杀死他。并且你总是可以在处决他之后解释说他可能是你的"干扰项"。这个策略在你用正常手段无法处决某位玩家的情况下特别有效。尤其是你能够通过这种方法让[[圣徒]]或者[[镇长]]被处决，或者至少让善良阵营团队不去相信他们。甚至还能够让像[[送葬者]]，[[共情者]]或者类似的角色的信息变得疑点重重。

* 时刻记得[[占卜师]]也可以选择查验死亡的玩家，甚至可以选择查验自己。告诉其他玩家你查验的一个死亡玩家是恶魔会让其他玩家怀疑自己之前所得到的信息，也暗示了（在只有一个爪牙的对局中）只剩下一个邪恶阵营玩家存活了。这个错误信息看起来没什么用，但实际上会由于场上存活玩家之间的不信任让游戏朝着你希望的方向发展。如果恶魔不小心杀死了[[守鸦人]]，这时候你可以说这个[[守鸦人]]是恶魔自杀假扮的，这时候会非常有效。

* 如果你是[[小恶魔]]，你可以公布你是[[占卜师]]然后策略性地在晚上死去，这样就可以让你的信息看起来更合理。

* 如果你是[[红唇女郎]]，你可以公开针对真的恶魔然后让他被处决。这会让[[送葬者]]这类的角色得到一个信息"被处决的人是[[小恶魔]]"，以此来证明你是个真的[[占卜师]]。

== 角色信息 ==

* 英文名：Fortune Teller

* 所属剧本：[[暗流涌动]]

* 角色类型：[[镇民]]

* 角色能力类型：[[获取信息]]、[[进场能力]]、[[持续检测型能力]]、[[互动干扰]]

* 角色背景相关：占卜师的干扰项并不是他的“宿敌”，他只不过是因为某个善良角色身上的香水味道过敏而导致判断失误了。

''其他称呼（非官方，仅方便索引用）：预言家、算命师''
