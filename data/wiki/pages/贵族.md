== 角色能力 ==

'''在你的首个夜晚，你会得知三名玩家：其中有且只有一名玩家是邪恶的。'''

== 角色简介 ==

贵族能得知三名玩家中的一名是邪恶的。

* 贵族只会在第一个夜晚得知他的信息。

* 如果贵族在游戏中途被创造，他会在自己作为贵族时的第一个夜晚得知信息。

* 贵族得知的是两名善良玩家和一名邪恶玩家。他不会得知一名善良玩家和两名邪恶玩家，也不会得知三名邪恶玩家。

== 范例 ==

 [[贵族]]得知了小明、小艾和小黑。小明和小艾是善良玩家，小黑是邪恶玩家。

 [[贵族]]得知了道哥、小兰和小八。道哥是[[共情者]]。小兰是[[圣徒]]。小八是[[陌客]]，但被[[贵族]]当作了邪恶阵营。

 第三个夜晚，[[麻脸巫婆]]把小艾变成了[[贵族]]。小艾得知了小文、小美和小佳中有一名邪恶玩家。小美是邪恶的[[间谍]]，但被当作善良阵营。与此同时小佳是[[珀]]，同样也是邪恶玩家。

== 运作方式 ==

在为首个夜晚进行准备时，将贵族的“得知”标记分别放置在两名善良玩家和一名邪恶玩家的角色标记旁。

在首个夜晚，唤醒贵族，并指向三名标记有“得知”的玩家。让贵族重新入睡。

== 提示标记 ==

* 得知

放置时机：在为首个夜晚做准备时放置。

放置条件：放置在三名玩家的角色标记旁边。这三名玩家需要满足两名为善良阵营，一名为邪恶阵营。

移除时机：在贵族获取信息后，说书人可以任由自己方便来进行移除。

== 规则细节 ==

*特定角色互动：
**[[异教领袖]]：就算在首夜因为自身能力就变为邪恶，也不会被贵族当做邪恶玩家得知。因为异教领袖的首夜行动顺序在贵族之后，他在贵族在被唤醒时始终都是善良的。
**[[舞蛇人]]：可能在贵族醒来之前阵营发生交换，所以在贵族信息中需要展示新的阵营状态。
**[[莽夫]]：在贵族醒来时，莽夫的阵营可能已经变为邪恶，所以可以将莽夫作为邪恶玩家展示。注意，贵族没有使用自身能力选择莽夫。
**[[陌客]]/[[间谍]]：可以被贵族当作邪恶或善良。

== 伪装成贵族 ==
*伪装成贵族最简单的方法就是尽早现身，然后指出三名善良玩家。这也会很有趣！如果你是邪恶的，说出三名善良玩家中有一名是邪恶的可以在他们之间引发猜忌，此外还有个额外的好处就是这种指证很难被证实或证伪。不同于[[镜像双子]]中，善良玩家能确切知道另一名玩家是邪恶的，或是[[共情者]]得知一名邻座是邪恶的（这意味着两名邻座互相知道对方是邪恶的），贵族所得知的玩家可以既宣称自己是善良的又相信另一名贵族得知的玩家是善良的。善良玩家互相说服对方自己是善良阵营这件事是非常自然和可信的（因为他们是善良的），但带来的继发效应是你看起来也是善良的，而玩家目前没有提及的第三名玩家看起来显得邪恶。说服（其他玩家）他们是善良的等于说服（其他玩家）一名善良玩家是邪恶的。

*让善良玩家自己去探讨三名玩家中哪一名是邪恶的。只要他们最终认为是邪恶的玩家实际上是善良的，你就不会受到怀疑。对于假冒的贵族而言，轻劝和建言比直言斥责更有效，倾听比夸夸其谈更有帮助。假装自己是团队一员去帮助他人。

*如果你自认有冒险精神，并且游戏中有三名或更多的邪恶玩家，宣称自己是贵族并指出两名（或三名）邪恶玩家作为你得知的三名玩家必定能够在善良玩家之间引起骚乱。他们很难怀疑贵族玩家提供的三名玩家中有两名或三名是邪恶的，因为即使真正的贵族醉酒了，说书人也不太可能会这么操作。提供即使是醉酒的玩家也不太可能获得的信息确实会让善良阵营陷入混乱。但要注意，你宣称的三名玩家中至少有一名会被认为邪恶而处决，也许是两名或全部。

*如果你是恶魔，伪装成贵族并给出正确的信息是相当容易的，而且会让你看起来善良。这是一种安全有效的伪装。不同于宣称是[[调查员]]看到[[男爵]]但是外来者人数对不上的发言，或是宣称是[[送葬者]]看到[[麻脸巫婆]]被处决但是没有人转变角色，简单地指出哪些玩家是邪恶的要容易得多，因为这很难被证伪。即使游戏中有一些在场角色比如[[罂粟种植者]]或[[魔术师]]让你无法确定哪些玩家是爪牙，或是你是刚被转变为[[方古]]或刚从[[舞蛇人]]转变，你都很可能在随机选择三名玩家时选中一个爪牙。如果你想让自己看起来善良并且安全，牺牲一个爪牙伪装成贵族去提供正确信息是非常容易做到的。
