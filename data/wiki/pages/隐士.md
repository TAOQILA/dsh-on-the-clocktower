== 角色能力 ==

'''你拥有所有外来者能力。[-0~1外来者]'''

== 角色简介 ==

隐士没有自己的命运，他活在他人的命运之中。

* 隐士同时拥有角色列表中所有其他外来者的能力。他不会拥有不存在于角色列表中的外来者能力。

* 即使角色列表包含超过4名外来者，隐士也会拥有所有外来者的能力。

* 如果有一名外来者的能力类型是死后能力保留，例如陌客，隐士会在死亡时保留他的能力，但不保留其他类型的能力。

* 如果隐士拥有酒鬼的能力，他不会得知自己是隐士，而他也同时拥有其他外来者的能力。一个同时拥有酒鬼和陌客能力的隐士可以被当作一名邪恶角色。

* 如果隐士获得了具有相克规则的角色能力，那么这条相克规则对隐士也适用。

* 由于隐士的设置调整，在初始设置需要移除一名外来者角色时，你可以移除隐士——这样外来者的数量就会少一名。如果你这样做了，隐士可以作为恶魔的伪装之一。

== 范例 ==

 小文是[[隐士]]，拥有[[呆瓜]]、[[管家]]和[[陌客]]的能力。每个夜晚，由于[[管家]]的能力，他要选择一名玩家作为他的主人。[[守鸦人]]死亡时选择了小文，小文的[[陌客]]能力让他得知了[[堤丰之首]]。小文死于处决了，由于[[呆瓜]]的能力，他需要选择一名玩家。小文选择了[[巫师]]，善良阵营落败。

 小佳是[[隐士]]，拥有[[酒鬼]]、[[畸形秀演员]]和[[心上人]]的能力。她以为她是[[驱魔人]]，每个夜晚都选择了一名玩家。小佳认为她可能是[[酒鬼]]，说书人认为她正在“疯狂”地证明自己是[[酒鬼]]，由于[[畸形秀演员]]的能力，说书人处决了她。小佳死于处决后，由于[[心上人]]的能力，[[炼金术士]]醉酒了。

== 运作方式 ==

设置游戏时，你可以移除一个外来者并添加一名镇民，或者不改变外来者数量。

当你认为合适的时候，以其他外来者角色的运作方式来让隐士行动，包括在夜晚唤醒隐士，以及任意使用其他外来者的提示标记。如果隐士和其他外来者同时在场，使用隐士的“1”、“2”、“3”提示标记作为替代。

如果多个外来者的能力产生了一定冲突，你可以自创一条规则来解决，并在游戏开始前告知所有玩家。例如，隐士同时获得了管家和狂热者的能力，你可以告知玩家，隐士必须要在主人投票的时候投票。

== 提示标记 ==

* 1&2&3
说明：当隐士和需要使用提示标记的外来者同时在场时，用隐士的“1”（或‘2’或‘3’）标记作为该角色的标记作为替代，用法与该外来者角色的提示标记一致。

== 规则细节 ==

* 相克规则：（如同角色简介中所写）如果隐士获得了具有相克规则的角色能力，那么这条相克规则对隐士也适用。

==伪装成隐士==

* 注意有多少名玩家声称自己是外来者。如果说书人给了你[[隐士]]作为伪装之一，那就好好利用——说书人可能特意把[[隐士]]移除来让你有空间去伪装一名外来者。或者，说书人也可能给你一个不同的外来者作为伪装，因为[[隐士]]的能力减少了一个外来者。

* 质疑其他声称自己是外来者的玩家。因为你的能力可能已经移除了一个外来者玩家了，所以场上不应该存在那么多外来者。

* 私下询问说书人你获得的多个能力之间的运作交互！有些时候能力的组合并不会很容易理解，但确保自己理解说书人的规则一定是有帮助的！例如，如果你拥有了[[管家]]和[[狂热者]]的能力，说书人可能规定你必须要在主人投票的时候投票，或者也可能是你任何时候只能拥有其中一种能力。不论哪种规则，你都需要知道说书人如何运作你的角色能力。
**任何一个玩家都有可能去和说书人确认规则，所以如果你没有提前确认[[隐士]]在这个剧本中如何运作，伪装[[隐士]]是有一定风险的。如果你声称你的能力以某种方式运作，而一名善良玩家询问说书人获得了不同的答案，你可能就会被抓住了。

* 注意你伪装时而不得不做的事情！如果你是[[狂热者]]，当五名及以上玩家存活时你都需要投票；但当你是一个拥有[[狂热者]]、[[呆瓜]]和[[月之子]]能力的[[隐士]]时，你不仅要记得每次提名时投票，还需要记得在死亡时进行[[呆瓜]]和[[月之子]]的选择！
**除了伪装自己正拥有这些能力以外，别忘了这些能力带来的结果。如果你声称自己是[[魔像]]，但提名了没有造成死亡，你应该声称那名玩家是恶魔，或者你自己在提名时中毒或者醉酒了。
