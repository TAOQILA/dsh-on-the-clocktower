== 角色能力 ==

'''恶魔的负面能力对你无效。'''

== 角色简介 ==

士兵无法被恶魔杀死。

* 士兵无法因为恶魔的能力而死去。因此，如果小恶魔在夜晚攻击士兵，无事发生。没有任何人会死亡。小恶魔也不能再去选择攻击另外一名玩家。

* 即使发起提名的玩家是恶魔，士兵仍然会因为处决而死亡。士兵的能力会保护自己不被恶魔的能力杀死，但无法保护自己被恶魔玩家的其他行为杀死。

== 范例 ==

 [[小恶魔]]攻击了[[士兵]]。[[士兵]]没有死亡，因此当晚无人死亡。

 [[投毒者]]让[[士兵]]中毒，然后[[小恶魔]]攻击了[[士兵]]。[[士兵]]死亡，因为他在处于中毒状态时失去了能力。

 [[小恶魔]]攻击了[[镇长]]。说书人选择由[[士兵]]来代替[[镇长]]死亡。然而，因为[[士兵]]无法被恶魔杀死，当晚无人死亡。
 ''（备注：这个例子只是作为解释镇长的能力逻辑用，在实际游戏中，你很少会遇到需要非得士兵或者是其他无法死去的玩家代替镇长死亡的情况，因此通过镇长的能力造成夜晚无人死亡的操作不建议频繁发生。具体可以看[[镇长]]条目下“运作方式”里的设计师建议）''

== 运作方式 ==

在夜晚时，如果恶魔攻击了士兵，士兵仍然存活。（在黎明时，宣布当晚没有人死亡。）

 在其他剧本中，恶魔可能会拥有除杀死以外的其他能力。士兵的保护能力同样可以阻止恶魔的其他有害效果，例如让士兵中毒或将士兵转变为邪恶阵营。

== 提示标记 ==

无

== 规则细节 ==

* 与[[僧侣]]的能力相似，[[士兵]]能够免疫的有害效果包括：死亡，醉酒，中毒，疯狂，阵营变化，来自与自身阵营不同的恶魔对他进行的角色变化，等等。

* [[士兵]]无法免疫的效果包括：来自与该玩家（保护目标）阵营相同的恶魔对他进行的角色变化，照看[[小怪宝]]，成为[[痢蛭]]的寄生对象（只会让[[士兵]]免疫中毒，但[[痢蛭]]的免死能力还是会与[[士兵]]绑定），等等。

* 相克规则：
**[[利维坦]]：如果利维坦提名并处决了士兵，善良阵营获胜。
**[[暴乱]]：如果暴乱提名并处决了士兵，善良阵营获胜。

== 伪装成士兵 ==

当你要伪装成士兵的时候，这里有几件事你应该记住：

* [[士兵]]很容易伪装，因为你不需要给出任何信息，你的能力也能解释为什么你能活这么久。但这并不意味着你就可以高枕无忧了；由于你没有信息，当大家的选择面缩减之后，很容易就会开始怀疑你。一个尝试帮助善良阵营玩家的[[士兵]]（例如你伪装成了[[占卜师]]来诱使恶魔攻击）要比一直坐着不说话的[[士兵]]可信的多。

* 保持安静并试图不引起他人的注意会让你看起来像是一个强力角色，但也有可能是[[士兵]]想要吸引恶魔的注意。安静的坐着并且一连几天都对你的能力只字不提，这样在大家看来你就是真的想被恶魔当做目标了。

* 你（或你方恶魔）可以在晚上攻击一个已经死亡的玩家。这将会造成当晚无人死亡的假象，能够让你声称昨夜应该是自己成为了恶魔的目标。

* 由于不死的能力存在，那些能获取信息的角色经常会伪装成[[士兵]]。如果要取得一名玩家的信任，你可以先将自己伪装成[[士兵]]，然后跟他们交换角色来保证他们能够一直存活。（温馨提示：如果你方刚好有一个[[投毒者]]在场，让这位玩家一直活着能够完全摧毁他的能力！）

* [[士兵]]在晚上不会死(除非中毒或者是个[[酒鬼]])。如果你死了，你最好对发生的事情有个合理的解释！

== 角色信息 ==

* 英文名：Soldier

* 所属剧本：[[暗流涌动]]

* 角色类型：[[镇民]]

* 角色能力类型：[[保护]]

* 角色背景相关：虽然士兵不会被恶魔杀死，但在这个怀疑与猜忌遍布的小镇上，这并没有对他带来多少帮助。人们还是选择处决了他，然后他在被收殓时，[[送葬者]]发现了他的真实角色（参考[[送葬者]]的背景故事）。此外，在士兵的台词中，大卫与歌利亚的战斗出自《圣经》旧约《撒母耳记》第17章，忒修斯与米诺陶的战斗出自希腊神话，阿周那与福授的战斗出自印度神话史诗《摩诃婆罗多》。忒修斯的神话也衍生出了哲学问题“忒修斯之船”（又称忒修斯悖论）。

''其他称呼（非官方，仅方便索引用）：军人''
