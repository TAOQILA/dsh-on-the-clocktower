== 角色能力 ==

'''如果恶魔杀死了你，在当晚你会被唤醒并得知两名玩家，其中一名是杀死你的那个恶魔。'''

== 角色简介 ==

贤者在活着的时候什么也不知道，但当贤者被恶魔杀死时，他会得知谁是恶魔。

* 贤者只有在被恶魔杀死时才会获取信息，死于处决时不会。

== 范例 ==

 第二个夜晚，恶魔杀死了[[贤者]]。说书人为[[贤者]]指出了两名玩家，其中一名是恶魔。

 在最后一夜，恶魔杀死了醉酒的[[贤者]]。说书人为[[贤者]]指出了一名死亡玩家和剩下的一名存活善良玩家，没有给他正确信息。

 [[麻脸巫婆]]创造了一名恶魔。因为[[麻脸巫婆]]的能力，当晚由说书人来选择杀死谁。说书人决定旧恶魔死亡，[[贤者]]也死亡，且当晚这些恶魔选择攻击的目标中没有[[贤者]]。因为[[贤者]]死于[[麻脸巫婆]]，而非恶魔，所以[[贤者]]不会醒来也不会得知任何信息。

== 运作方式 ==

如果贤者被恶魔杀死，唤醒贤者。指向两名玩家，其中一名是杀死贤者的恶魔。让贤者重新入睡。

 如果贤者在游戏前期死亡，你可能会想给贤者展示两名存活玩家，因为这能让邪恶阵营仍然有微弱的获胜机会。如果贤者在游戏的最后一个夜晚死去，你可以指向一名存活玩家和一名已死亡的玩家。

== 规则细节 ==

* 相克规则：
**[[陌客]]：陌客可能会被贤者当作杀死他的恶魔。
**[[利维坦]]：每个夜晚*，利维坦要选择一名存活的善良玩家（与之前的每个夜晚不同）：如果贤者被选择，他的能力生效但不会死亡。
**[[暴乱]]：每个夜晚*，暴乱要选择一名存活的善良玩家（与之前的每个夜晚不同）：如果贤者被选择，他的能力生效但不会死亡。

== 伪装成贤者 ==
* [[贤者]]的能力只和死亡有关，而且非常强大。如果你打算一直伪装[[贤者]]，那么你就需要做好死亡的准备。这是值得的——如果善良玩家相信你，他们会花两天去处决那些你指认的并不是恶魔的人！如果你是[[方古]]（一个可能在击杀外来者后死亡的角色），或者一个[[麻脸巫婆]]导致随机死亡的邪恶玩家，这都会特别有效。

* 作为邪恶玩家，你肯定想要活的更久，以产生更大的影响。这会让你伪装成[[贤者]]更为困难 ，因为如果你没有在夜晚死亡，就没有足够的“信息”来支持你的伪装，但是你可以把这个当做你的另一种武器。你可以尽快和一些人交流（你知道的善良玩家，尤其是那些有强大能力的[[博学者]]或者是[[卖花女孩]]这样的），并告诉他你是[[贤者]]。在之后，如果有人怀疑你，你可以说你只和一个人透露了你的角色，并指控他要么是恶魔，要么是给恶魔透露了你的信息。

* 如果你开始伪装的是一个有信息的角色，而大家认为你的信息有问题，那么你可以考虑不再伪装那个角色而是告诉大家你是[[贤者]]。你的信息可能不是正确的，但是善良玩家可能认为你是有更好的理由（为了引起恶魔注意）而撒谎，所以会不考虑你是坏人。
