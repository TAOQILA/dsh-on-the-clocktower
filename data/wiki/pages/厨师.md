== 角色能力 ==

'''在你的首个夜晚，你会得知场上邻座的邪恶玩家有多少对。'''

== 角色简介 ==

厨师会得知是否有邪恶玩家相邻而坐。

* 在第一个夜晚，厨师会得知有多少对邪恶玩家相邻而坐。两名相邻而坐的玩家为一对，然而每名玩家都能分别与两侧的玩家各组成一对。因此，两名相邻而坐的玩家是一对，三名相邻而坐的玩家是两对，四名相邻而坐的玩家是三对，以此类推。

* 厨师会像探查其他角色类型一样探查邪恶旅行者，但仅仅只会关注那些在厨师行动前加入游戏的旅行者。

== 范例 ==

 没有邪恶玩家相邻而坐。[[厨师]]得知了“0”。

 [[小恶魔]]与[[男爵]]相邻而坐。在另一侧，[[投毒者]]与[[红唇女郎]]相邻而坐。[[厨师]]得知了“2”。

 邪恶的[[替罪羊]]坐在[[小恶魔]]与[[红唇女郎]]的中间。在另一侧，[[投毒者]]与[[男爵]]相邻而坐。[[厨师]]得知了“3”。

 [[陌客]]坐在[[小恶魔]]与[[投毒者]]的中间。[[厨师]]得知了“1”。此时，[[陌客]]在“[[小恶魔]]-[[陌客]]”这一对里被当作了邪恶阵营，但在“[[投毒者]]-[[陌客]]”这一对里被当作了善良阵营。
 ''（备注：这个例子只是想举例说明厨师对阵营的探查是分多次进行，且陌客能在不同的能力不同的时间点下被视为不同的阵营或角色。在实际游戏中，因为厨师这样的多次探查能力非常少见，因此如果想采用这种给“1”的信息方式，建议说书人应该提前告知玩家，否则应该默认这种情况下要么得知“0”，要么得知“2”。在[[陌客]]的范例中，也可以看到实际上对这个例子以及“1”的结果避而不提。）''

== 运作方式 ==

在首个夜晚里，唤醒厨师。为厨师用手势比划场上互为邻座的邪恶玩家有多少对（0，1，2，等等）。让厨师重新入睡。

== 提示标记 ==

无

== 规则细节 ==

* [[厨师]]的单次能力会为玩家进行多次检测判断。因此具有[[互动干扰]]类能力的角色可能会在与其左右相邻的玩家组合中被当作不同的阵营。但通常来说，我们建议按照在[[厨师]]的单次能力探查中始终保持同一阵营来进行判断，以提升[[厨师]]玩家的游戏体验。毕竟，不仅[[互动干扰]]能力会影响厨师的结果，[[醉酒]]和[[中毒]]也会。

* [[厨师]]的能力探查的是相邻玩家，且并未加“存活”这一附加条件。在游戏中途产生的[[厨师]]，获取到的信息仍然会考虑仍然在游戏中的所有玩家（已经提前离开游戏的旅行者则不算在内）。

== 伪装成厨师 ==

当你要伪装成厨师的时候，这里有几件事你应该记住：

* 宣称场上没有或者只有一对邪恶阵营玩家邻座通常都是比较可信的。报出更大的数字，例如有两对或者三对邪恶阵营玩家邻座在概率上通常不太可能，因此也不太会被人相信。在人数较少的游戏中，声称场上有两到三对邪恶阵营的玩家邻座通常没什么意义，因为场上一共就只有两位邪恶玩家。

* 给出错误的信息能够让善良阵营的玩家感到非常困惑。如果善良阵营认为邪恶玩家是邻座的，但实际上不是的话（反之亦然），他们就会就会因为各自的嫌疑而互相攻击，而你只需要隔岸观火。

* 给出真的信息能够让善良玩家确定一些玩家的阵营并厘清状况。这样当然也会带给你一些好处，因为你已经为善良阵营提供了很多帮助，那他们就会相信你并且让你活着。又或者如果他们觉得你是邪恶阵营的，那他们通常会觉得你给出的信息是假的，也就是说从一开始他们推理的基础就错了。

* [[厨师]]是一个相当容易伪装的角色。如果你是个新手，装成[[厨师]]能够在玩家中散布错误信息，而又不需要随着游戏的进行持续地更新你的信息。
