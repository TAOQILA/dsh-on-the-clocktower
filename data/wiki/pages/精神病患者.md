== 角色能力 ==

'''每个白天，在提名开始前，你可以公开选择一名玩家：他死亡。'''

'''如果你被处决，提名你的玩家需要和你猜拳，只有你输了你才会死亡。'''

== 角色简介 ==

精神病患者在光天化日之下展开杀戮。

* 在白天时，如果精神病患者宣布自己是精神病患者并公开选择一名玩家，那名玩家死亡。这个能力每个白天只能使用一次，且只能在说书人要求开始提名前进行。

* 精神病患者的能力并非强制使用，他可以在自己不想要使用能力时不这么做。

* 精神病患者能够正常被提名和投票。如果精神病患者被处决，他可能不会死亡。他会和提名他的玩家进行一次猜拳（石头剪刀布）。提名他的玩家需要赢得猜拳才能让这次处决成功杀死精神病患者。如果平局或者猜拳失败，精神病患者会仍然存活。

* 对精神病患者的处决同样计入每个白天限制一次的次数里。如果精神病患者被处决，那么今天白天不会再有其他提名和处决发生了。

* 如果精神病患者因为其他原因死亡，例如恶魔的攻击，那么他不会进行猜拳，而是直接死亡。

== 范例 ==

 在第一个白天，小米宣称自己是[[精神病患者]]，并选择了小文。小文死亡。

 [[精神病患者]]选择攻击[[水手]]。[[水手]]没有醉酒，因此没有死亡。今天[[精神病患者]]无法再次使用他的能力了。

 [[精神病患者]]被[[理发师]]提名并因此被处决。在猜拳中，[[理发师]]出了石头，[[精神病患者]]也出了石头，因此[[精神病患者]]仍然存活。在下一个白天，[[圣徒]]提名并处决了[[精神病患者]]。[[圣徒]]出了布而[[精神病患者]]出了剪刀，因此[[精神病患者]]仍然存活。在下一个白天，[[理发师]]再次提名并处决了[[精神病患者]]。[[理发师]]出了石头而[[精神病患者]]出了剪刀，[[精神病患者]]死亡。

== 运作方式 ==

每个白天限一次，在你宣布开始提名之前，精神病患者可以公开选择一名玩家。那名玩家死亡。

如果精神病患者被处决，他需要与提名他的玩家进行猜拳。如果精神病患者在猜拳中输了，那么他死亡。如果精神病患者在猜拳中平局或获胜，他会仍然存活。不论猜拳是哪种结果，白天阶段会随即结束，因为每个白天只会有一次处决发生。

如果精神病患者因为提名自己或是某些角色的能力效果而被处决，那么他会改为和你进行猜拳。

== 规则细节 ==
*特定角色互动：
**[[炼金术士]]：如果炼金术士获得精神病患者的能力并提名贞洁者而因此被处决，他将会和说书人猜拳。
**[[咖啡师]]：“行动两次”的效果将允许精神病患者在白天杀死2人（咖啡师可能会被立即流放），但如果在接下来的这个白天精神病患者被处决，仍然只会进行一次猜拳。
**[[屠夫]]：每天都可以重新提名精神病患者来进行第二次处决并尝试杀死他。
**[[魔鬼代言人]] ：即使受到魔鬼代言人的保护，精神病患者仍然应该进行猜拳，只有当他输了时，善良阵营才会发现精神病患者受到了魔鬼代言人的保护，因为精神病患者没有死于一次“猜拳胜利”的处决。
**[[弄臣]]/[[水手]]/[[茶艺师]]：如果精神病患者的目标不能死亡，目标不会死亡。这会被数学家记录。
**[[法官]]：如果法官强制使对精神病患者的提名通过，这只能确保精神病患者被处决，并且将需要进行猜拳来确定他是否会死亡。
**[[呆瓜]]/[[月之子]]：如果精神病患者杀死他，他会在白天得知他的死亡，因此必须在同一天做出选择。
**[[亡骨魔]]：如果精神病患者被亡骨魔杀死并因此在死亡状态保留了他的能力，如果他在死亡状态被处决，则没有必要进行猜拳——他已经死亡，因此无论猜拳的结果如何都不会再次死亡。

* 相克规则：
**[[小怪宝]]：如果精神病患者正照看小怪宝，他会在被处决时死亡。

* 相克规则（与华灯系列角色）：
** [[姑获鸟]]：如果姑获鸟获得了精神病患者的能力，他会在被处决时死亡。

== 对抗精神病患者 ==
*在[[精神病患者]]表明角色并使用能力之前，没有太多针对的事情可以做。直到他们的处决失败时，你才会的得知精神病患者在场，那时你可以制定处理他们的策略。
*一旦[[精神病患者]]暴露了自己，请考虑尽快处决他们。每天提名并处决他们，直到[[精神病患者]]不幸输掉猜拳而死去。这种策略在精神病患者很早表明角色的多人游戏中是最好的。花几天时间将他处决掉是值得的，以免他杀死三、四、五甚至更多玩家。
*一旦[[精神病患者]]暴露了自己，只要没有充分的理由杀死另一名玩玩家，考虑每天都处决[[精神病患者]]。如果你不知道恶魔是谁，最好一遍又一遍地处决[[精神病患者]]并希望好运发生。当游戏有四、五或六名玩家活着时，您可以将注意力转移到寻找恶魔上。
*一旦[[精神病患者]]暴露了自己，如果您对恶魔可能是哪个玩家有一两个线索，那就晾着精神病患者不管。通常最好的办法是杀死恶魔而不是浪费处决机会在[[精神病患者]]身上。
*如果团队的策略是杀死[[精神病患者]]，请确保你每天投票一致。犹豫反复只会让邪恶的团队受益。
*如果团队的策略是让[[精神病患者]]活着并找到恶魔，请对你更强大的角色能力保持沉默，以尽可能少向精神病患者提供信息。与你信任的玩家（或任何除精神病患者之外的玩家，真的）交谈，并秘密整理你的信息。[[精神病患者]]可能会随时偷听你们私聊，所以要小心，并随时小声私聊。或者，为了消除[[精神病患者]]干扰，如果您是一个不介意死亡的角色，请公开装作[[精神病患者]]想要杀死的角色，例如[[赏金猎人]]或[[渔夫]]。或者，如果你是一个绝对不想死的角色，就公开谎称是一个精神病患者懒得碰的角色，比如[[厨师]]或[[告密者]]。
*当提名开始时，尽早提名[[精神病患者]]。如果提名成功，那将是你和精神病患者猜拳，你至少确定你属于善良阵营。警惕其他过于着急提名[[精神病患者]]的玩家，因为他们可能是提名[[精神病患者]]的邪恶玩家，目的是故意输掉猜拳。
