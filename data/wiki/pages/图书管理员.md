== 角色能力 ==

'''在你的首个夜晚，你会得知两名玩家和一个外来者角色：这两名玩家之一是该角色（或者你会得知没有外来者在场）。'''

== 角色简介 ==

图书管理员会得知一个特定的在场外来者角色，但不知道是谁在扮演该角色。

* 在第一个夜晚，图书管理员会得知两名玩家其中一人的外来者角色。

* 图书管理员只会得知一次信息，之后便无法获取更多信息。

* 酒鬼是外来者。如果图书管理员得知两名玩家中有酒鬼，他不会得知酒鬼玩家以为的那个镇民角色。

== 范例 ==

 小八是[[圣徒]]，小莱是[[男爵]]。[[图书管理员]]得知要么小八是[[圣徒]]，要么小莱是[[圣徒]]。

 说书人决定将[[陌客]]当作一名爪牙而不是外来者。现在场上没有其他外来者了。[[图书管理员]]得知了“0”。

 小黑是[[酒鬼]]，且以为自己是[[僧侣]]。道哥是[[送葬者]]。[[图书管理员]]得知要么小黑是[[酒鬼]]，要么道哥是[[酒鬼]]。[[酒鬼]]是小黑的实际角色，即使他以为自己是[[僧侣]]。

== 运作方式 ==

在为首个夜晚进行准备时，将图书管理员的“外来者”提示标记放置在任意一个外来者角色标记旁，然后将图书管理员的“错误”提示标记放置在任意其他角色标记旁。

在首个夜晚里，唤醒图书管理员，并指向标记有“外来者”和“错误”的玩家。将有“外来者”的玩家的角色标记展示给图书管理员。或者，如果说书人由于场上无外来者而未放置这两个标记，则对图书管理员展示手势“0”。让图书管理员重新入睡。在说书人方便的时候，移除图书管理员的提示标记。

== 提示标记 ==

* 外来者

放置时机：在为首个夜晚做准备时放置。

放置条件：放置在一个对应外来者角色或能被当作外来者角色的角色标记旁边。

移除时机：在图书管理员获取信息后，说书人可以任由自己方便来进行移除。

* 错误

放置时机：在为首个夜晚做准备时放置。

放置条件：放置在未放置“外来者”提示标记的其他任意一个角色标记旁边。

移除时机：在图书管理员获取信息后，说书人可以任由自己方便来进行移除。

== 规则细节 ==

* 如果在首夜就中毒或醉酒，[[图书管理员]]可能会得知错误的玩家（没有放置他的提示标记的玩家），或得知错误的角色，或两者兼而有之。但即使如此，说书人也应该让[[图书管理员]]得知外来者角色，否则等同于在明示[[图书管理员]]他自己醉酒中毒了，且给出的信息也不符合[[图书管理员]]应该获取的信息内容。

* 因为给出“0”这样的信息也在[[图书管理员]]的合理信息范围内，因此醉酒或中毒的[[图书管理员]]在某些情况下，说书人也可以给出“0”这样的信息以进行信息混淆。（如场上有[[酒鬼]]，但本剧本中还含有[[哨兵]]的时候，玩家将无法确信场上是否有外来者）但大部分时候，在很容易能确定场上有外来者的场合下给出“0”这样的信息，基本上等同于明示[[图书管理员]]醉酒了。

*特定角色互动：
**[[陌客]]：在仅有一名外来者且为[[陌客]]的情况下，[[图书管理员]]可能会将[[陌客]]当作非外来者角色，从而得知没有外来者在场。
**[[间谍]]：[[图书管理员]]能将[[间谍]]当作外来者，并得知[[间谍]]和任意其他玩家之中有一个任意外来者角色。

== 伪装成图书管理员 ==

当你要伪装成图书管理员的时候，这里有几件事你应该记住：

* 你可以用你的信息给你的邪恶阵营同伙提供支持，这能让他们看起来显得比较善良。这不但能提高他们发言的可信度（尤其是当他们说自己是[[圣徒]]或[[陌客]]的时候），而且你们还可以明目张胆地合作，因为你们互相认为对方是"善良阵营的玩家"。

* 你也可以用你的信息去支持一个善良阵营的玩家。[[圣徒]]可能会面临不被其他玩家相信的难题，[[管家]]也可能希望有人能够相信他。这时候他们会很乐于让[[图书管理员]]来确认他们的角色，这之后他们也会更愿意相信你，还会跟你投票。

* 将两名善良玩家定义为[[酒鬼]]能够让他们怀疑自己所获得的信息，或者削弱像[[镇长]]这样的强力角色。[[酒鬼]]是一个非常安全的选择，因为你所挑选的玩家将没有办法证实你的信息（至少短期内不能）。

* 你也可以说你的邪恶阵营同伴有可能是[[酒鬼]]。这就意味着即使他们在角色伪装上出现了失误（例如给出了矛盾的信息），也还有回旋的余地。这时候你就可以说他们应该是真的[[酒鬼]]了。

* 作为一种自信的体现，在游戏前期立即声明在场的外来者角色，但不要指出可能是哪些玩家。如果你声明的角色在场，就能够让善良阵营的玩家相信你；如果你猜错了在场的外来者角色，那就可以让邪恶阵营的玩家去伪装成这个角色。

== 角色信息 ==

* 英文名：Librarian

* 所属剧本：[[暗流涌动]]

* 角色类型：[[镇民]]

* 角色能力类型：[[获取信息]]、[[进场能力]]

* 角色背景相关：询问图书管理员想要借阅“药典”的，很有可能就是准备去熬药的[[麻脸巫婆]]。（那么被图书管理员错认成外来者是不是因为图书管理员中毒了呢）
