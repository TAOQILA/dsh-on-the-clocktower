== 角色能力 ==

'''每个夜晚，你要选择一名玩家和一个善良角色。他明天白天和夜晚需要“疯狂”地证明自己是这个角色，不然他可能被处决。'''

== 角色简介 ==

洗脑师促使玩家假装成与自己实际角色不同的角色。

* 洗脑师会选择让一名玩家“疯狂”地证明自己是某个镇民或外来者角色。被选择的玩家明天必须试图说服其他玩家相信他是这个角色，否则就会死亡。

* 简短的暗示不足以避免死亡。玩家必须付出努力说服其他玩家。虽然疯狂的玩家不会被强迫一定要说出他不想说的东西，但是如果说书人感受不到他的努力，他就会付出代价。

* 疯狂的邪恶玩家可能会以这种方式被处决，但“可能”意味着你可以选择不这么做，以防止邪恶玩家通过这种策略获胜。

* 像畸形秀演员一样，执行处决惩罚计入每天的处决限制。

== 范例 ==

 [[洗脑师]]使[[理发师]]“疯狂”地证明他是[[博学者]]。第二天，[[理发师]]声称自己是[[博学者]]，并拜访说书人，然后告诉其他玩家两个编造的信息。当被问及他是否疯狂时，[[理发师]]断然说“不”来避免被处决。

 [[洗脑师]]使死亡的[[艺术家]]“疯狂”地证明他是[[贤者]]。第二天，[[艺术家]]没说自己是[[贤者]]。所以[[艺术家]]被处决。

 [[洗脑师]]使[[卖花女孩]]“疯狂”地证明她是[[钟表匠]]。[[卖花女孩]]对其他玩家说，她是[[钟表匠]]，并得知恶魔与爪牙的最近距离是“2”，但私下暗示其他玩家她疯狂了。这一举动被说书人发现了，并处决了[[卖花女孩]]。

== 运作方式 ==

每个夜晚，唤醒洗脑师。让洗脑师指向一名玩家和角色列表上一个镇民或外来者图标。让洗脑师重新入睡。为这名玩家放置“疯狂”提示标记并唤醒这名玩家，依次向他展示“该角色的能力对你生效”信息标记、洗脑师的角色标记、他要疯狂证明的角色标记。让那名玩家重新入睡。

在下一个白天或夜晚，如果被选择的玩家没有尽最大努力去说服其他玩家他是被选择的角色，你就可以处决他。向所有玩家宣布他的死亡。如果你在白天的常规处决前处决了他，则直接进入夜晚阶段。（每个白天最多一次处决。）

== 提示标记 ==

* 疯狂

放置时机：在洗脑师夜晚行动并选择了玩家和善良角色后。

放置条件：在洗脑师要洗脑的玩家，其角色标记旁放置。若此时洗脑师醉酒中毒，不放置该标记。

移除时机：在下一个夜晚的黎明时，或洗脑师死亡或离场时。（在实体游戏中，因为只有一个“疯狂”标记，因此需要说书人在洗脑师第二夜行动后，转移疯狂标记，但需要注意此时到黎明之前，上一夜洗脑师选择的玩家仍然还处于疯狂状态，并且可能会因为不够疯狂而被处决。）

== 规则细节 ==
* 相克规则：
**[[哥布林]]：洗脑师可以选择将玩家洗脑成哥布林。

== 对抗洗脑师 ==
* 确保你理解了什么是“疯狂”。如果你疯狂了，或者你正在和一个处于疯狂状态的玩家交流，知道疯狂是如何运作的是非常重要的。如果[[洗脑师]]让你对一个特殊的角色进行疯狂，你必须尽自己的最大努力让大家相信你是这个特殊的角色，否则说书人将会处决你。告诉玩家你是哪个角色，如果这个角色应该获得信息，就要编造一些信息给到大家。如果另外一个玩家也声称自己是这个角色，告诉大家他在撒谎，因为你就是那个角色。让大家相信你就是[[洗脑师]]让你疯狂的那个角色，就是你需要做的所有的一切。需要注意的是，在白天开始时单单只是陈述“我是个[[筑梦师]]”（例如如果[[洗脑师]]已经把你洗脑成[[筑梦师]]）然后在中途保持沉默将可能被处决。你对大家说的是什么并不重要，但是你的语气，热情和论点的力度是非常重要的。如果说书人认为你是在真正努力说服善良阵营你是那个角色，那么说书人几乎不会处决你。

* 如果你被[[洗脑师]]影响而疯狂了，而你没有努力让大家相信你是这个新的角色，说书人可能会处决你。有时候被处决是可以接受的，甚至对你的团队是有帮助的。例如，如果你是个[[神谕者]]，你有大量的有关死亡玩家的信息去告诉团队，但是由于疯狂却无法告诉他们，那么最好此时不要理会[[洗脑师]]的疯狂，告诉团队你是[[神谕者]]，然后告诉他们你的信息，最后被说书人直接处决。有时候你的信息比你的生命更加有价值。同样的，如果你不擅长进行疯狂的表演，说书人可能会处决你——这不是世界末日。继续游戏并且你有更多的时间去处决恶魔。

* 小心说书人！当玩家处于疯狂状态时，说书人通常会更加关注他在说些什么。例如，如果玩家公开声明自己是[[呆瓜]]（即试图让大家相信自己是个[[呆瓜]]），但是当他认为说书人在没有看他的时候眨了眨眼睛，或者私下偷偷地告诉他旁边的人实际上他是个[[舞蛇人]]，如果说书人在他表演过程中抓住了他们，他们可能会立即被处决。

* 小心邪恶的玩家！如果你对你是另一个角色而疯狂，但是你想私下告诉一两个玩家你的真正的角色是什么（当你认为说书人没有看你的时候），你可能会意外的和一个即将揭发你的邪恶玩家交谈。这个玩家如果向他的团队发出信号，或者他们直接告诉说书人你告诉了他们你的真正角色，这样可以让你被处决。

* 当你认为有人处于疯狂状态之中，不要对他们施加太大的压力，他们可能处于疯狂状态，他们也可能处于不同的原因撒谎。但是，如果你和大家都认为，一个处于疯狂状态的玩家说的话是因为他们疯狂了，那么说书人可能会处决有问题的玩家。

* [[洗脑师]]可以将死亡的玩家作为目标！鸦木布拉夫的居民们能够，甚至有些时候也必须要处决已死之人。这是个奇怪的地方。如果一名死亡玩家被[[洗脑师]]作为目标，那名玩家仍可能因为不够疯狂而被处决，因为每天只能执行一次处决，没有提名发生，今天不可能执行对其他玩家的处决，然后夜间将降临。

* 作为一个团队，当[[洗脑师]]存在于游戏之中时，你可能会知晓。玩家们可能会突然的被处决。然后这名玩家可能会告诉大家他在昨天，或者前几天，处于疯狂状态，如果他们不再疯狂，他们可以放心地这样做。请注意那些声称被[[洗脑师]]选中的玩家，回溯他们的信息，以获得谁是善良的谁是邪恶的信息。如果两名玩家都声称他们在前一晚上同时被[[洗脑师]]选择了，那么他们至少有一个人在撒谎，且撒谎的玩家可能是邪恶的。[[洗脑师]]总是大概率选择善良阵营的玩家，而且几乎永远不会选择恶魔（这太冒险了！）除非他们有意图的死亡，否则你可以永远放心地假设之前被选择的玩家并不是恶魔。让这些玩家存活，即使你认为他们可能是爪牙，因为专注于寻找并杀死恶魔才是你最重要的事情。
