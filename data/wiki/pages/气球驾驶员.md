== 角色能力 ==

'''每个夜晚，你会得知一名与上个夜晚得知的玩家角色类型不同的玩家。[+0~1外来者]'''

== 角色简介 ==

气球驾驶员能得知不同角色类型的玩家。

* 气球驾驶员每次必须得知不同于上一次得知玩家的角色类型的玩家。

* 气球驾驶员不会得知玩家的角色类型。

* 向气球驾驶员展示的玩家可以存活或死亡。

* 向气球驾驶员展示的玩家可以善良或邪恶。

* 如果气球驾驶员中毒或醉酒，他可以得知与上一次得知玩家的角色类型相同的玩家。如果之后气球驾驶员恢复了健康清醒，他们必须得知与上一次得知玩家的角色类型不同的玩家。

* 设置调整阶段，说书人可以决定是否让气球驾驶员添加一名额外的外来者。

== 范例 ==

 小艾是[[维齐尔]]，小莱是[[女祭司]]，小美是[[政客]]。首个夜晚，[[气球驾驶员]]得知了小艾。第二个夜晚，[[气球驾驶员]]得知了小莱。第三个夜晚，[[气球驾驶员]]得知了小美。

 小朱是[[守夜人]]，小艾是[[士兵]]，小兰是[[解谜大师]]。首个夜晚，[[气球驾驶员]]得知了小朱。第二个夜晚，[[投毒者]]选择了气球驾驶员。由于[[气球驾驶员]]中毒了，说书人决定让[[气球驾驶员]]得知了另一个镇民小艾。第三个夜晚，[[气球驾驶员]]恢复了健康清醒并得知与小艾不同角色类型的小兰。

== 运作方式 ==

在设置调整阶段，你可以额外增加一名外来者。

在为首个夜晚进行准备时，将“得知”提示标记放置在任意一名玩家的角色标记旁。之后每个夜晚的准备阶段，将“得知”提示标记放置在一名与当前放置着该提示标记的角色类型不同的玩家角色标记旁。

每个夜晚，唤醒气球驾驶员。指向被放置“得知”提示标记的玩家。然后让气球驾驶员入睡。

== 提示标记 ==

* 得知

放置时机：在为每个夜晚做准备时放置。 

放置条件：首个夜晚放置在任意一名玩家的角色标记旁边；之后的每个夜晚放置在与当前放置着“得知”提示标记的角色类型不同的玩家角色标记旁边。

特殊说明：如果气球驾驶员因其他能力得知错误信息（如中毒醉酒）或上个夜晚得知的玩家角色类型发生变化时，将该标记移动到给气球驾驶员展示的玩家角色标记旁。

移除时机：气球驾驶员死亡或离场时。

== 伪装成气球驾驶员 ==

* 由于气球驾驶员可能会让游戏中多出一名外来者，你可以让某个爪牙冒充外来者，制造出“确实多了一名外来者”的假象，让你的伪装听起来更可信。

* 多和善良玩家聊天，弄清他们声称的角色类型，然后再结合这些信息编出更“合理”的说法。

* 留意那些手里握有信息、并且暗示其他玩家是邪恶阵营的善良玩家。例如，如果[[调查员]]说他看到[[僧侣]]可能是[[投毒者]]，那你就声称你在前后两晚看到了这两个玩家。不仅能让[[僧侣]]看起来像个真[[投毒者]]，还能顺带获得[[调查员]]的信任！

* 不要把你的角色告诉太多人，这样你活到游戏后期时别人也不容易起疑。毕竟气球驾驶员每晚都能获得新信息，越往后越关键，恶魔当然早就想把真气球驾驶员干掉。

* 声称你接连两晚看到的都是爪牙，这样会让人以为其中有个爪牙其实是好人——如果这个爪牙正在冒充[[洗衣妇]]或[[事务官]]之类的角色就更好了。反过来也可以反咬一口，说这两名玩家一个是爪牙一个是恶魔，毕竟正常来说两名爪牙不太可能被你连续得知，对吧？

* 观察善良玩家之间的信任关系链。如果你说自己连续两晚看到的两个玩家都是镇民，而这俩人又彼此很信任，他们很可能会开始怀疑你。所以更好的做法是：盯上那些不太信任彼此的好人。如果[[送葬者]]怀疑[[镇长]]是恶魔，那你就说自己先看到了[[送葬者]]，第二晚看到的是[[镇长]]，然后坐等他们互相怀疑、场面混乱。

* 别急着公开你“知道”的那些信息。气球驾驶员是最难伪装的角色之一，因为你开局其实根本不知道谁是镇民、谁是外来者。多等几天、观察局势后再慢慢开口，这样更容易让你编出来的信息看起来靠谱。你说的内容未必完全对，但一定要听起来对。

* 如果你的同伙里有[[寡妇]]或[[间谍]]，尽早找他们要魔典的详细信息！伪装成一个“信息正确”的气球驾驶员，是个很棒的方式，让大家觉得——“他最多是个[[间谍]]，肯定不是恶魔啦！”
