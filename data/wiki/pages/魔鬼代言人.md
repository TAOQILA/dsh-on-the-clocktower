== 角色能力 ==

'''每个夜晚，你要选择一名存活的玩家（与上个夜晚不同）：如果明天白天他被处决，他不会死亡。'''

== 角色简介 ==

魔鬼代言人能在处决中拯救玩家。

* 每个夜晚，魔鬼代言人需要选择一名存活的玩家，保护他不会因处决而死亡。在下一个白天，如果该玩家被处决，处决会成功但该玩家依然存活。

* 魔鬼代言人不能连续两个夜晚选择同一名玩家，无论该玩家是否从处决中被救出，并且魔鬼代言人也不能选择被当作死亡的僵怖。

== 范例 ==

 在夜晚，[[魔鬼代言人]]保护了自己。在下一个白天，[[魔鬼代言人]]被处决但依然存活。

 [[魔鬼代言人]]保护了[[僵怖]]。[[僵怖]]被处决但依然存活，因此其生命标记不翻面。在下一个白天，[[僵怖]]再次被处决，并且被当作已死亡。

 [[魔鬼代言人]]保护了[[教父]]。[[教父]]被处决但依然存活。之后，[[魔鬼代言人]]保护了[[修补匠]]。[[修补匠]]被处决，但是由于[[修补匠]]的能力，说书人还是杀死了[[修补匠]]。（注：此时说书人宣布的是修补匠被处决，然后死亡，但并没有说明死亡原因，因此可能会被其他玩家误以为修补匠是死于处决）之后，[[魔鬼代言人]]保护了[[月之子]]，并且[[法官]]强制让本次处决成功——处决被执行，但[[月之子]]依然存活。

== 运作方式 ==

每个夜晚，唤醒魔鬼代言人。让魔鬼代言人指向任意一名玩家。如果魔鬼代言人选择了他上一夜曾选择的玩家或已死亡的玩家，提醒他更换目标。让魔鬼代言人重新入睡。将“处决不死”提示标记放置到该玩家的角色标记旁。

如果标有“处决不死”的玩家被处决，宣布该玩家被处决但依然存活。（不要说明原因。）

== 提示标记 ==

* 处决不死

放置时机：在魔鬼代言人行动并选择了玩家后放置。

放置条件：在魔鬼代言人选择的玩家角色标记旁放置。魔鬼代言人不能选择已经放置有“处决不死”标记的玩家。如果魔鬼代言人醉酒中毒，该标记不会有任何效果，但你仍然需要放置该标记，用于提示在下一夜让魔鬼代言人不能选择今夜选择的这名玩家。在魔典中将提示标记倒置，代表该提示标记没有任何效果，仅用于标记该玩家被魔鬼代言人选择过。

移除时机：在魔鬼代言人选择了下一个目标后，或魔鬼代言人死亡或离场时。

== 规则细节 ==

无

== 对抗魔鬼代言人 ==

当你要对抗魔鬼代言人的时候，这里有几件事你应该记住：

* 当玩家被处决但没有死亡时，尽你所能确定原因。游戏中可能有[[茶艺师]]或[[和平主义者]]，或者被处决的玩家可能是[[弄臣]]或[[水手]]。如果你认为被处决的玩家是好人，你可以让他们活着，但如果你认为玩家是邪恶的并受到[[魔鬼代言人]]的保护，那么稍后再处决他们。

* 连续两次处决可疑的玩家。由于[[魔鬼代言人]]不能连续两次保护同一个玩家，如果玩家在今天的处决中幸存下来，明天杀死他们是规避棘手的[[魔鬼代言人]]的可靠方法。

* 如果您认为某人是邪恶的并且非常强烈地引导大家处决那个玩家，请等待一天并在明天处决该玩家。[[魔鬼代言人]]希望你处决受他们保护的玩家，所以如果你注意哪些玩家正在努力引导特定玩家被处决，你可以避免他们的能力生效，同时仍然处决你想要的玩家。

* 一旦你发现有[[魔鬼代言人]]在场，立即处决他们！虽然你可以忽略其他一些爪牙，但[[魔鬼代言人]]却不能。例如，如果你知道[[男爵]]是谁，你可能最好将注意力集中在其他玩家身上，并让[[男爵]]继续活着。或者，如果你确定了哪个玩家是[[刺客]]，你可以把他晾着，然后全力以赴处决恶魔。然而，[[魔鬼代言人]]真的，真的，无论如何都要死去才能获胜。如果可能的话，在将注意力集中在恶魔身上之前处决[[魔鬼代言人]]。
