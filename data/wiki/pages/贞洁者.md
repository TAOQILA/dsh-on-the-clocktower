== 角色能力 ==

'''当你首次被提名时，如果提名你的玩家是镇民，他立刻被处决。'''

== 角色简介 ==

贞洁者不会被处决……也许吧。提名贞洁者的玩家通常会死亡。

* 如果一名镇民提名了贞洁者，那名镇民会立即被处决。因为每天只能有最多一次处决，提名的流程会立即结束，即使有其他玩家被提名且即将被处决。

* 只有镇民才会被贞洁者的能力处决。如果外来者，爪牙或恶魔提名了贞洁者，无事发生，并且提名流程会继续。

* 贞洁者的能力非常强大，因为如果有镇民提名了贞洁者并死亡，那么几乎可以确定这两名角色一定都是镇民。

* 当第一次被提名后，贞洁者会失去能力，即使发起提名者没有死亡，或者贞洁者处于醉酒或中毒状态。

== 范例 ==

 [[洗衣妇]]提名了[[贞洁者]]。[[洗衣妇]]被处决，并且投票终止。

 以为自己是[[厨师]]的[[酒鬼]]提名了[[贞洁者]]。[[酒鬼]]仍然存活，并且[[贞洁者]]失去了他的能力。因为[[酒鬼]]是一名外来者而不是镇民。接下来玩家可以选择投票是否处决[[贞洁者]]。

 一名已死亡的玩家提名了[[贞洁者]]。然而已死亡玩家无法发起提名。说书人宣布这次提名无效。[[贞洁者]]不会因此失去他的能力。

== 运作方式 ==

如果首次提名贞洁者的玩家是镇民，立即宣布那名发起提名的玩家被处决。那名玩家死亡——在魔典中将帷幕标记放置在其角色标记上。贞洁者失去他的能力——将贞洁者的“失去能力”提示标记放置在其角色标记旁。终止提名流程并推进至夜晚阶段。（今天白天没有其他人能被处决。）

如果首次提名贞洁者的玩家不是镇民，照常继续进行投票。贞洁者失去他的能力——将贞洁者的“失去能力”提示标记放置在其角色标记旁。

== 提示标记 ==

* 失去能力

放置时机：在贞洁者被首次提名时。

放置条件：在贞洁者角色标记旁放置。不论贞洁者是否醉酒中毒，都要放置该标记。

移除时机：贞洁者死亡或离场时。

== 规则细节 ==

* 如果提名[[贞洁者]]的玩家其镇民角色不会因为处决而死亡（如[[弄臣]]、[[水手]]或被[[魔鬼代言人]]保护的玩家），则说书人会宣布该玩家被处决但没有死亡（不会说明具体原因），然后因为有处决发生，所以白天阶段依然会立即结束。

* 如果提名[[贞洁者]]的镇民玩家同时被[[女巫]]诅咒，则女巫的诅咒与贞洁者的处决在同一时间被触发。在这种情况下，由说书人来对以何种顺序结算这两个效果做出决定，但应该倾向于产生更多信息的结果（参考[[隐性规则汇总|隐性规则]]第1条，同时触发）。因此，在大部分情况下，即使该玩家的角色是还未触发能力的[[弄臣]]，也建议当晚[[送葬者]]依然能够得知该玩家的角色。

== 伪装成贞洁者 ==

当你要伪装成贞洁者的时候，这里有几件事你应该记住：

* 善良玩家绝不会因为提名你而被处决。这就意味着当你被提名的时候，你们两个中的一个将会是邪恶的，或是至少是酒鬼。如果你可以的话，让一个被大家怀疑是邪恶阵营的玩家提名你。在这种情况下，如果大家相信他邪恶，你就会被大家相信是善良的。

* 如果一个[[贞洁者]]被提名了，提名者与被提名者中但凡有一个是[[酒鬼]]，[[贞洁者]]的能力都不会被触发。[[贞洁者]]是[[酒鬼]]的话会在游戏开始就失去能力，提名者是[[酒鬼]]的话他就是外来者（而不是镇民）。如果在提名你之后没有玩家被处决，你就可以提出一个强有力的假设——你们两个之中有一个[[酒鬼]]。这样做还有一个好处，就是那个真的[[酒鬼]]可能不会被大家发现。

* 如果你是爪牙，你可以让恶魔来提名你然后把嫌疑引到自己身上。你越像邪恶阵营的人，恶魔就越像好人，因为恶魔在你伪装的角色下本是要被牺牲的角色，其他玩家因此就会更偏向于相信他。

* 如果场上真的有[[贞洁者]]，你的伪装就要小心一点了。如果你告诉大家你是[[贞洁者]]，而真[[贞洁者]]通过处决了一个镇民证明了自己，你就肯定不可能是[[贞洁者]]了。你需要让一个邪恶阵营角色去提名真[[贞洁者]]，避免他的角色被证实，这样善良阵营就会一直无法判断你们到底谁是真[[贞洁者]]。

* 伪装成[[贞洁者]]，被提名然后继续活下去，这是个伪装成其他角色的好机会。即便你在前一两天说了你是[[贞洁者]]，后面再说你其实是个[[送葬者]]或者[[僧侣]]之类的角色也是可信的。因为恶魔通常不会想杀一个有邪恶嫌疑的[[贞洁者]]，他们会更想杀[[送葬者]]或者[[僧侣]]。这时候再说"我刚才撒谎说我是某某角色"就看起来很合理了。

* 如果你确信大家都相信你是[[贞洁者]]，就可以坚持让那个对你威胁最大的玩家提名你！他们没有被处决的话看起来就会非常可疑。例如，一个[[共情者]]给邪恶阵营造成了很多麻烦，你就可以坚持让他提名你，从而让大家把矛头对准他。

* 英文名：Virgin

* 所属剧本：[[暗流涌动]]

* 角色类型：[[镇民]]

* 角色能力类型：[[提名]]、[[处决]]、[[限次能力]]
