== 角色能力 ==

'''每个夜晚*，你会得知今天白天死于处决的玩家的角色。'''

== 角色简介 ==

送葬者会得知当天因处决而死亡的角色。

* 只有死于处决的玩家才会被送葬者得知是哪一种角色。在白天因为其他原因造成的死亡，例如枪手杀死的玩家，或对旅行者的流放，不算在内。

* 送葬者会在除首个夜晚以外的每晚醒来，因为在首个夜晚之前不会有任何处决发生。

* 如果当天没有玩家死亡，送葬者不会得知任何消息。说书人在夜晚时要么不唤醒送葬者，要么唤醒他但并不对他展示角色标记。

* 如果酒鬼被处决，送葬者会被展示酒鬼标记，而非那名酒鬼玩家以为自己是的那个镇民标记。

== 范例 ==

 [[镇长]]今天被处决。当晚，[[送葬者]]被展示了[[镇长]]标记。

 以为自己是[[贞洁者]]的[[酒鬼]]今天被处决。[[送葬者]]被展示了[[酒鬼]]标记，因为[[送葬者]]得知的是玩家实际角色，而不是玩家以为的那个角色。

 [[间谍]]被处决。两名旅行者被流放。在当晚，[[送葬者]]被展示了[[管家]]标记，因为此时[[间谍]]被当作了[[管家]]，且流放并不是处决。

 今天白天没有人被处决。当晚，[[送葬者]]没有被唤醒。

== 运作方式 ==

如果一名玩家死于处决，将送葬者的“死于今日”提示标记放置在那名死亡玩家的角色标记旁。

除首个夜晚以外的每个夜晚，如果当天有任何玩家死于处决，唤醒送葬者。向他展示被标记了“死于今日”的角色标记。让送葬者重新入睡。在说书人方便的时候，移除送葬者的提示标记。

 在《暗流涌动》里，每个白天只会有一场处决，且每次处决都会导致一名玩家死亡。在其他剧本中，每天可能会有多于一次的处决（在这种情形下由说书人决定向送葬者展示其中的哪一个角色标记），或发生了处决但并未导致死亡（在这种情形下送葬者不会得知任何消息）。

== 提示标记 ==

* 死于今日

放置时机：在白天时，如果有人因处决而死亡，在该玩家的角色标记旁放置。

放置条件：在因处决而死亡的玩家的角色标记旁放置，而不论此时送葬者是否醉酒中毒。

移除时机：在送葬者获取信息后，说书人可以任由自己方便来进行移除。

特殊说明：由于送葬者的能力为回溯型能力，因此如果送葬者在游戏中途产生，仍然要根据当前情况补放标记，而不是因为没有放置标记便不在夜晚告知送葬者信息。

== 规则细节 ==

* 如果白天无人被处决，或发生了处决但无人死亡，[[送葬者]]可能不会被唤醒，也可能会被唤醒但不得知任何消息。说书人可以自行决定并提前告知玩家本场游戏将以何种方式运作。然而，不论是否唤醒[[送葬者]]，都不应该对[[侍女]]获得的消息产生影响。（即：如果说书人决定不唤醒[[送葬者]]，那么无论实际操作中是否唤醒[[送葬者]]，[[侍女]]都不应探查到[[送葬者]]被唤醒，反之亦然。）

* 如果白天无人被处决，或发生了处决但无人死亡，但[[涡流]]在场，[[送葬者]]不会因此得知错误的信息。因为无人因处决而死，所以[[送葬者]]不会因此获得信息，也就不会受到[[涡流]]的影响。

* 在夜晚因处决而死亡的玩家其角色不会被[[送葬者]]得知。

== 伪装成送葬者 ==

当你要伪装成送葬者的时候，这里有几件事你应该记住：

* 一个优秀的[[送葬者]]会等几天再公布自己的角色。在你告诉别人你是[[送葬者]]之前，你可以心安理得地安静几天，或者说自己是某个其他角色，然后将伪装[[送葬者]]当作备用计划。

* 证实一个好玩家的角色能够让你显得善良。为了这个策略能够成功，你需要提前知道他的角色是什么。如果你是[[间谍]]，或者可以和[[间谍]]交流，那你就可以对此更自信，因为你已经能得知所有人的角色了。

* 如果一些关键玩家被处决的话，你能够通过声明他是爪牙或者恶魔的方式让他显得邪恶。这会有些冒险，因为那位玩家就会知道你是邪恶阵营的。这给你带来了获胜的可能性，因为剩下的玩家并不知道你在说谎。但实际上大多数时候善良阵营玩家被处决的数量要比邪恶阵营玩家多，因此最好谨慎地使用这个策略。

* 如果另一个邪恶玩家死于处决，你可以随意说他是善良角色或是邪恶角色。如果你说他们是善良角色，你们两个的信息能够互相佐证，这会让你们两个看起来都更可信。如果你说他是个邪恶阵营玩家，他应该表现的更邪恶一点，并且公然暗示他确实邪恶。事实上，验出邪恶阵营能够让你看起来更像一个[[送葬者]]。

* 暗中诋毁一个被处决的镇民的更好方法是说你看到了[[酒鬼]]的角色标记。如果其他人相信你（特别是如果被处决的玩家相信你），那其他玩家就会假设这个人收到的任何信息都不太可信了。如果你不知道一位玩家的角色是什么，声明他是[[酒鬼]]是个隐藏真相的好方法。
